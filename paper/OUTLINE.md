# Paper outline

Working title: **How Well Do Small Open LLMs Handle Northeast Indian Languages? An Empirical Study on Assamese, Manipuri and Bodo**

1. Introduction: low-resource language access, small open models, scope and measured contributions.
2. Related work: IndicGenBench, IndicParam, MILU, small multilingual models and Northeast MT shared tasks.
3. Benchmark/protocol: data provenance/license, language/script coverage, sample, model revisions, prompts, decoding and compute.
4. Results: translation chrF by language/direction/model; QA F1 only where coverage permits; condition deltas and uncertainty.
5. Error analysis: blinded sample, script/language mismatch, omissions, hallucinations, word sense and grammar.
6. Limitations: metric validity, benchmark coverage, script variants, rater coverage, prompt sensitivity and licensing.
7. Conclusion: only claims supported by measured results.

Tables: dataset counts; model/revision/license/compute; translation scores; supported QA scores; prompt deltas; error categories. Write abstract only after experiments.
